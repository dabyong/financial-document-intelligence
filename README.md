# AI Financial Document Intelligence System

An AI-powered financial analytics application that combines
SEC annual filings, structured financial data, and
Retrieval-Augmented Generation (RAG).

## Business Objective

Help analysts investigate company financial performance,
compare financial metrics, and answer questions using
evidence from official SEC filings.

## Initial Scope

- Companies: Alphabet and Meta
- Fiscal years: 2023-2025
- Source: SEC EDGAR 10-K filings and XBRL data

## Technology

- Python 3.12
- DuckDB and SQL
- ChromaDB
- Retrieval-Augmented Generation (RAG)
- Streamlit
- pytest
